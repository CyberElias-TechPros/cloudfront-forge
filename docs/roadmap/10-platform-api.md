# 10 — Platform & API workstream (PLAT + SEC)

**Purpose:** make the Cloudflare Worker API a stable, contract-first platform that two
clients (web + native Android) can build against in parallel, and turn "verified
attention" from a slogan into an enforced rule.

**Why this comes before screens:** Android cannot be built responsibly against a
hand-written client, and integrity cannot be claimed while `POST /watch` trusts the
client. Every task here is consumed by both `20-web.md` and `30-android.md`.

**Master plan:** [../ROADMAP.md](../ROADMAP.md) · **Findings:** [00-audit-and-baseline.md](00-audit-and-baseline.md)

## Phase SEC — Integrity, safety & data lifecycle (M1 → M4)

**Exit gate:** a scripted client that fakes watch time earns nothing; revenue-grade
decisions (payouts) depend only on server-observed evidence; members can export and
truly delete their data; the AI coach cannot be used to blow up the bill.
