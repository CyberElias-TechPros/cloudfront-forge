# 40 — Operations, data & growth workstreams (OPS / DATA / GRW)

**Purpose:** make the product operable at 3 a.m., measurable every morning, and growable
without guessing. These workstreams serve both web and Android; nothing here is optional
polish — each item prevents a specific, predictable failure.

## Launch readiness checklists

### Web launch (per major release)

- [ ] CI green: lint, typecheck, 26+ web tests, 303+ worker tests, contract check, bundle budget.
- [ ] Lighthouse ≥90/95/95 on `/` (mobile).
- [ ] Staging smoke: sign-in → join → submit → watch → claim → review → mission.
- [ ] Error budget healthy; alerts armed; on-call named.
- [ ] Rollback rehearsed (Vercel previous deployment + Worker version).
- [ ] Privacy/terms current; consent banner live if ads enabled in EEA.
- [ ] Analytics events firing; no PII in props.

### Android launch (per track promotion)

- [ ] `bundleRelease` signed, `versionCode` unique, targetSdk 36.
- [ ] Closed-track crash-free ≥99.5 % for 48 h; ANR ≤0.3 %.
- [ ] Pre-launch report triaged; no critical issues.
- [ ] Policy declarations submitted and accurate; reviewer access verified.
- [ ] Deep links verified on a Play-installed build (not debug-signed).
- [ ] Kill switches tested (AI, rewards, billing, player).
- [ ] Support briefed; canned responses ready; escalation path named.
- [ ] Rollout plan with halt criteria and the exact halt command documented.
